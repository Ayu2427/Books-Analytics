# CodeAlpha Internship Tasks — Data Analytics

This repository contains my completed CodeAlpha Data Analytics internship tasks.

## Completed Tasks

### Task 1 — Web Scraping
Python + Requests + BeautifulSoup used to collect book title, price, availability, rating, and product URL from Books to Scrape.

### Task 2 — Exploratory Data Analysis (EDA)
Pandas and NumPy used for data cleaning, data-type inspection, missing-value and duplicate checks, descriptive statistics, correlation analysis, and price outlier detection.

### Task 3 — Data Visualization
Matplotlib and Power BI used to communicate price and rating patterns through KPI cards, rating distribution, price distribution, price-vs-rating scatter analysis, top-10 price analysis, and slicers.

## Technology Stack

Python • Requests • BeautifulSoup • Pandas • NumPy • Matplotlib • Power BI • Streamlit • GitHub

## Source Dataset

Books to Scrape is a sandbox website created for web-scraping practice. Its displayed prices and ratings are randomly assigned for demonstration, so the analysis is presented as an educational analytics workflow rather than real market intelligence.
