# Power BI Dashboard Guide

1. Open Power BI Desktop.
2. Select **Get Data → Text/CSV** and import `data/books_clean.csv`.
3. Confirm `Price_GBP` is Decimal Number, `Rating_Num` is Whole Number, and text fields are Text.
4. Add KPI cards for book count, average price, median price, and average rating.
5. Add visuals for rating distribution, price distribution, price vs rating, top 10 books, and a detailed table.
6. Add slicers for Rating and Availability.
7. Add a text box with key analytical findings.
8. Save the dashboard as `Books_Analytics_Dashboard.pbix`.

Suggested title: **BOOKS TO SCRAPE — PRICE & RATING ANALYTICS**

The source website is intended for scraping practice and its displayed prices and ratings are randomly assigned for demonstration purposes.
